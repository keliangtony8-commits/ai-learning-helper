# AI Learning Helper

把一本书变成一条学得下去的闭环：上传、拆成章节、选一段跟着学、当场做题、按遗忘曲线复习。

当前版本：**0.4.2**

## 这一版是什么

原生安卓应用，包名 `dev.ailearning.helper`。不是网页套壳。

安装包：`dist/app-debug-0.3.0.apk`。最低 Android 8。书存在手机本地，不上传。

还没接模型。粘贴进来的文字按空行分成段，讲义和题目由规则生成。

## 学习闭环

1. 书架：一本书一个进度，不堆功能入口。
2. 章节：选今天要学的那一段。
3. 带着学：先讲清楚，再让你用自己的话复述。
4. 做题：选择、简答，错了给依据，不只给对错。
5. 复习：到期的内容排在今天，不靠你自己记得回来。

## 怎么看

用手机安装 `dist/app-debug-0.4.2.apk`。调试签名，第一次安装需要允许未知来源。这版把模型密钥打进了包里，只给自己装，不要外发。

## 版本

见 `CHANGELOG.md`。版本号在 `VERSION`。用户能看见的改动必须升版本并写进变更记录。
