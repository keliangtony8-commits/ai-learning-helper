# AI Learning Helper

把一本书变成一条学得下去的闭环：上传、拆成章节、选一段跟着学、当场做题、按遗忘曲线复习。

当前版本：**0.1.0**

## 这一版是什么

手机优先的学习界面原型。这台环境还没有 Java / Android SDK，所以 0.1.0 先交付可在手机浏览器里打开的 App 壳，交互、排版和动效按正式 App 来做。安卓安装包是后续版本，不在这一版假装完成。

## 学习闭环

1. 书架：一本书一个进度，不堆功能入口。
2. 章节：选今天要学的那一段。
3. 带着学：先讲清楚，再让你用自己的话复述。
4. 做题：选择、简答，错了给依据，不只给对错。
5. 复习：到期的内容排在今天，不靠你自己记得回来。

## 怎么看

用手机浏览器打开 `app/index.html`，或在电脑上把窗口缩到手机宽度。

## 版本

见 `CHANGELOG.md`。版本号在 `VERSION`。用户能看见的改动必须升版本并写进变更记录。
